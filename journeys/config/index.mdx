AWS Config gives you a detailed view of how the resources in your AWS account are configured,
how they relate to one another, and how their configurations change over time.

This journey explains AWS Config from the ground up, one short step at a time. You don't need an
AWS account to follow along. Each step links to the AWS documentation it's based on.
