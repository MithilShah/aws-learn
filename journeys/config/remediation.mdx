When a rule flags a resource as noncompliant, AWS Config can remediate it using AWS Systems
Manager Automation documents, which define the actions to take. AWS Config provides managed
automation documents, and you can also create your own.

## What this step covers

- How remediation actions work
- Manual and automatic remediation
- Managed and custom Automation documents
