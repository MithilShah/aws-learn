When you turn on AWS Config, it first discovers the supported resources in your account and
creates a configuration item for each one. It then keeps recording new configuration items as
those configurations change.

## What this step covers

- Resource discovery and tracking
- What's inside a configuration item
- The configuration recorder and recording frequency
- Where the data goes: Amazon S3 and Amazon SNS
- Querying your resources with advanced queries
