An AWS resource is something you work with in AWS, such as an Amazon EC2 instance, an Amazon EBS
volume, a security group, or an Amazon VPC. As an application grows, so does the number of
resources behind it, and keeping track of how each one is set up gets harder. AWS Config keeps
that record for you.

## What this step covers

- The problem AWS Config solves
- Four ways teams use it: resource administration, auditing and compliance, managing and
  troubleshooting configuration changes, and security analysis
- What you need before you turn it on
