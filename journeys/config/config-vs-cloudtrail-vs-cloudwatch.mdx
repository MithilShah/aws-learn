AWS Config, AWS CloudTrail and Amazon CloudWatch all help you keep an eye on your AWS account, so
they're easy to mix up. Each one answers a different question. AWS Config tells you what a
resource looked like at a point in time. CloudTrail tells you who made the API call that changed
it. CloudWatch monitors your resources and applications in real time.
