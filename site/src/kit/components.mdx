built only in development and for the browser tests, never for the live site.

<Callout type="misconception">
AWS Config rules don't prevent changes. They evaluate a resource's configuration after the change
has been recorded.
</Callout>

## Evaluation results

A rule's result is one of <CompliancePill status="COMPLIANT" />, <CompliancePill status="NON_COMPLIANT" />,
<CompliancePill status="ERROR" /> or <CompliancePill status="NOT_APPLICABLE" />.

## Key terms

<KeyTerms>
  <Term name="Configuration item">A point-in-time view of the attributes of a supported AWS resource.</Term>
  <Term name="Configuration recorder">Stores the configuration changes to the resource types in scope as configuration items.</Term>
</KeyTerms>
